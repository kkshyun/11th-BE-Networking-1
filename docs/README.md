### 기능 목록
1. 자동차 이름 입력 받기
   - 이름 검증(5자 이하만 가능)
   - 사용자가 잘못된 입력을 할 경우 예외(IllegalArgumentException) 발생 & 애플리케이션 종료
2. 자동차 이동 횟수 입력 받기
   - 사용자가 잘못된 입력을 할 경우 예외(IllegalArgumentException) 발생 & 애플리케이션 종료
3. 주어진 횟수 동안 자동차 전진 또는 멈춤
   - 무작위 값(0에서 9사이)을 구한 후 무작위 값이 4 이상일 경우 전진
   - 각 차수별 실행 결과 출력
4. 경기 결과 출력
   - 가장 많이 전진한 자동차가 우승
   - 우승자가 여러 명일 경우 쉼표를 이용하여 구분
